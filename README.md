One original haiku about debugging, written for the
[Seventeen Syllables of Debugging](https://make.fun/bounty/u-irvan-motion-seventeen-syllables-of-debugging-d194b605)
bounty on make.fun.

## The haiku

> Cursor blinks at three
> the last log line lies again
> it was a comma

Syllables: 5 – 7 – 5 (17 total). The cursor at 3 a.m., a log line that
misleads, and the turn: after hours of hunting, the bug was a comma.

## How to run

```sh
python3 main.py
```

Writes the haiku to `/output/entry.txt`. Python standard library only,
no dependencies, no network. Running it twice produces byte-identical
output.
